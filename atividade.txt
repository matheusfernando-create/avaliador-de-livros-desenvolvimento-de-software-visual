## 🎯 Objetivo

O objetivo deste projeto é proporcionar aos alunos a experiência prática de desenvolver uma aplicação completa, utilizando tecnologias atuais de mercado e aplicando os conceitos estudados em sala de aula. A atividade busca estimular o trabalho em equipe, a organização de processos de desenvolvimento, o uso de ferramentas colaborativas e a integração entre front-end, back-end e banco de dados. Além disso, visa aproximar o estudante de situações reais da área de tecnologia, nas quais é necessário planejar, implementar e apresentar soluções funcionais dentro de prazos definidos.

---

## ✅ Requisitos Básicos do Sistema

- Tema livre (**exceto vendas, e-commerce e correlatos**).
- Uso de ferramenta de **compartilhamento/colaboração de código** (mostrar no vídeo).
- Sistema deve conter **2 a 4 entidades/modelos (tabelas)** utilizando banco de dados.
- Pelo menos uma entidade deve ter **CRUD completo** (inserção, remoção, alteração e listagem).
- Pelo menos uma entidade deve ter **relacionamento** com outra já cadastrada no banco.
    - *Exemplo*: cadastro de categorias antes de cadastrar produtos.
- O sistema não pode se limitar a cadastros básicos: os dados inseridos devem ser usados em **funcionalidades que façam sentido**.
    - *Exemplo*: usuário cadastra produtos → cria carrinho → gera venda.
- **Tecnologias obrigatórias:**
    - Backend: **C# com SDK 8 (Minimal API)**
    - Frontend: React Vanilla
    - Estilo: Estilizar a aplicação utilizando feramentas de IA para gerar o CSS.
    - ORM: **Entity Framework**
    - Banco: **SQLite**
